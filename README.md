# SF-sql-homework

## Описание
Проект содержит SQL-скрипты для работы с четырьмя базами данных.

## Структура проекта

### 1. vehicles/ — Транспортные средства
Таблицы: Vehicle, Car, Motorcycle, Bicycle

### 2. car-racing/ — Автомобильные гонки
Таблицы: Classes, Cars, Races, Results

### 3. hotel-booking/ — Бронирование отелей
Таблицы: Hotel, Room, Customer, Booking

### 4. organization/ — Структура организации
Таблицы: Departments, Roles, Employees, Projects, Tasks

## Как запустить
1. Открой PgAdmin 4
2. Создай базу данных
3. Выполни schema.sql для создания таблиц
4. Выполни data.sql для заполнения данными
5. Выполни нужный task*.sql для проверки решения

## Структура каждого раздела
- schema.sql — создание таблиц
- data.sql — тестовые данные
- task1.sql, task2.sql... — решения задач
